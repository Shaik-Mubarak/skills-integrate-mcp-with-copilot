## Environment Configuration

This project now supports environment-based configuration using `src/config.py` and `.env`.

- Copy `.env.example` to `.env` for local development.
- Set `SECRET_KEY`, `DATABASE_URL`, and `APP_ENV` in `.env`.
- `.env` is ignored by Git to keep secrets out of source control.
